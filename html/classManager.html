Подробное описание

Обеспечивает взаимодействие расчётного ядра и коммуникатора

Класс предназначен для координирования действий расчётного ядра и интерфейса взаимодействия с пользователем. Также замеряет время работы расчётного ядра

Методы

◆ run()

void Manager::run ( )

Запуск программы: приветствие, сбор данных для расчёта, передача собранных данных расчётному ядру, замер времени работы расчётного ядра, получение результатов расчёта и вывод с помощью Communicator в консоль

Объявления и описания членов классов находятся в файлах:

  • src/Manager.cpp
