Приложение для численного интегрирования методом трапеций с распараллеливанием.
Для расчёта необходимо ввести входные данные:
  - a: double, нижняя граница отрезка интегрирования
  - b: double, верхняя граница отрезка интегрирования
  - function_string: string, интегрируемая функция одной переменной, заадётся одной формулой с использованием переменной x
  - threads_num: int, количество используемых нитей для расчёта
  - steps: int, количество шагов интегрирования

Для исользования приложения необходимо установить [muparser](https://beltoforion.de/en/muparser/building.php#idCMake). Также используется OpenMP для параллельных вычислений.

Сборка:  
``` 
cmake -S . -B build/ 
``` 
Компиляция:  
```
cmake --build build/  
```
Запуск:  
```
./build/main  
``` 

Сборка библиотеки muparser:
```
cd muparser/build/
cmake ..
make install
```
